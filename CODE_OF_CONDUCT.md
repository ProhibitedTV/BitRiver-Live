# Code of Conduct

BitRiver Live is committed to a respectful, constructive community.

## Expected behavior

- Be respectful and assume good intent.
- Focus feedback on ideas, code, docs, and behavior rather than people.
- Welcome newcomers and explain context without gatekeeping.
- Share criticism clearly and kindly.
- Respect privacy and do not post secrets, personal data, or private logs without permission.

## Unacceptable behavior

- Harassment, intimidation, or personal attacks.
- Discrimination or hateful conduct.
- Trolling, deliberate disruption, or repeated bad-faith arguments.
- Doxxing or sharing private information without consent.
- Sexualized language or imagery in project spaces.

## Scope

This code of conduct applies in project spaces such as issues, pull requests, discussions, release notes, and other repository-linked communication channels.

## Reporting

If you experience or witness unacceptable behavior, use a private contact path for the repository owner or maintainer on the hosting platform rather than escalating publicly.

Please include:

- what happened
- where it happened
- any relevant links or screenshots
- whether there is an immediate safety concern

## Enforcement

Maintainers may remove comments, close threads, reject contributions, or restrict participation when behavior violates this code of conduct.

We want this repository to feel safe to learn from, review, and contribute to.
