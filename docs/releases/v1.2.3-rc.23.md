## Installation and remaining boundaries

Follow [Ubuntu installation](../installing-on-ubuntu.md) or
[quickstart](../quickstart.md). Download matching package/archive, checksums,
root and signature from this release; do not mix tags or copy historical digests.
Ubuntu 24.04 amd64 is the production target. Package acceptance is not clean
XOA/NPM installation, physical reboot, firewall/NAT or real-device media proof.
All external recovery/upgrade, capacity, resilience, SLO, security and viewer
evidence must bind to this exact root before stable promotion. No stable/latest
channel or operator deployment was changed.

The migration tree is unchanged from RC22; no candidate-specific migration or
backfill was introduced. That does not replace populated-state upgrade testing.
Back up database, volumes, env and generated config before rollout; follow
[upgrades](../upgrades.md) and [production release](../production-release.md).
There is no accepted previous v1.2.3 stable root for rollback. Do not downgrade
to rejected RC22; require a tested restore route and candidate-bound evidence.
