# BitRiver Live v1.2.3-rc.12

Status: published prerelease on 2026-07-31.

- [GitHub Release](https://github.com/ProhibitedTV/BitRiver-Live/releases/tag/v1.2.3-rc.12)
- Release commit: `3a9572f035bc3356378023f0c90f0d07e3f6e07f`
- Release workflow: `30672085853`

RC12 is the first candidate whose downloaded Linux package and launcher were
independently confirmed to reference the exact published candidate images. It
is suitable for evaluation and target-host acceptance work; it is not the
stable `v1.2.3` declaration.

## Install entry points

- Windows evaluation: clone the repository and run
  `.\scripts\verify-windows-docker.ps1 -Start` with Docker Desktop using Linux
  containers.
- Ubuntu Server 24.04 amd64: download
  `bitriver-live_v1.2.3-rc.12_amd64.deb` or
  `bitriver-launcher-linux-amd64.tar.gz` plus `CHECKSUMS.txt`, then follow
  [`../installing-on-ubuntu.md`](../installing-on-ubuntu.md).
- Source evaluation on Linux/macOS/Git Bash: follow
  [`../quickstart.md`](../quickstart.md).

Do not mix assets, checksums, signatures, image tags, or digests from different
releases.

## What ships

- Go server and CLI binaries for Linux, macOS, and Windows
- Source-free launcher archives for Linux, macOS, and Windows
- amd64/arm64 `.deb` and `.rpm` packages
- Windows MSI and Homebrew formula
- Prebuilt viewer bundle
- API, viewer, SRS controller, transcoder, and OME config helper images
- Artifact and container SBOMs, keyless launcher signature bundles, and
  `CHECKSUMS.txt`

## Known limits before stable promotion

- Ubuntu Server 24.04 amd64 is the packaged production target. Debian, RPM
  hosts, and arm64 have build/package evidence but remain provisional as
  production hosts.
- Clean installation on the intended XOA/XCP-ng VM has not yet been recorded.
- Browser and media behavior through the operator's real Nginx Proxy Manager,
  TLS, firewall, and NAT path still require acceptance evidence.
- Reboot recovery and repeated OME restart/media recovery remain unproved on
  the target host.
- HA, autoscaling, multi-host failover, and a managed service are outside this
  release's support boundary.

## Upgrade and rollback

Back up `/etc/bitriver-live`, Postgres, and `/var/lib/bitriver-live` before an
upgrade. Keep the previous package and its exact image digests available for
rollback. Follow [`../upgrades.md`](../upgrades.md) and
[`../production-release.md`](../production-release.md); never move or reuse a
published tag.
